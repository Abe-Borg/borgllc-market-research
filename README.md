# borgllc-market-research

Cumulative market research for a catalog of free, open-source business
applications aimed at small and midsize professional organizations.

Written to by an automated Claude task. See `INDEX.md` for the table of
contents and `ledger.json` for machine-readable state.

- `ledger.json` - completed assignments, active claims, backlog, cross-industry patterns
- `INDEX.md` - human-readable index, regenerated each run
- `reports/` - one markdown + one HTML report per completed assignment
